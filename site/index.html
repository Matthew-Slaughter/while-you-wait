while you wait

Devotional companionship for Christians who work with AI. A verse, a catechism answer, a hymn stanza or a theologian's line, every time you press enter.

“Be still, and know that I am God. I will be exalted among the nations, I will be exalted in the earth!”
— Psalm 46:10 (ESV)
Calvin: stillness is not idleness but the soul's posture before sovereignty. The Hebrew verb (rapha) means to let your hands drop, to cease striving — not absence of action but renouncement of self-rescue. While you wait, drop your hands; God runs the universe whether or not you are gripping the wheel.

Every entry is verbatim from a source you can open, and every reflection leads with a real human voice. How the corpus is curated explains what each entry has to pass. Nothing is sent anywhere; the corpus lives on your machine.

Claude Code (terminal) and Claude Desktop (Code tab)

One line in a terminal, then start a new session:

curl -fsSL https://matthew-slaughter.github.io/while-you-wait/install.sh | sh

The script is forty lines and only runs Claude Code's own plugin commands. Prefer to type them yourself? Either of these does the same thing:

claude plugin marketplace add Matthew-Slaughter/while-you-wait && claude plugin install while-you-wait@while-you-wait

Or inside any Claude Code session, terminal or desktop app, which share one configuration:

/plugin marketplace add Matthew-Slaughter/while-you-wait
/plugin install while-you-wait@while-you-wait

To get new entries automatically: /plugin, Marketplaces, while-you-wait, Enable auto-update. Otherwise run /plugin marketplace update while-you-wait and /plugin update while-you-wait@while-you-wait now and then.

Claude Desktop, Chat and Cowork tabs

Chat and Cowork have no per-prompt hook, so here the devotional is something Claude includes at the start of a conversation. It is one entry per day, the same all day, chosen from the date. Three steps, once.

1. Add the skill

Download the skill (zip)

In claude.ai or the desktop app: Settings, Capabilities (or Skills), Add custom skill, and upload the zip. The zip holds the same corpus as the plugin and a small script that picks the day's entry.

2. Ask for it every conversation

Add this sentence to Settings, Profile, personal preferences. Claude reads it in every conversation.

Begin each new conversation by running the while-you-wait skill and showing its entry, verbatim, before anything else.

3. Optional: a daily one in Cowork

In Cowork, schedule a recurring task with the prompt below. Each morning's run appears in the Scheduled list.

Run the while-you-wait skill and show today's entry verbatim. Then stop.

Because Claude decides when a skill applies, an occasional conversation may open without it. Say “give me a verse” and it will.

Codex CLI and the Codex app

Clone the repo and add the hook from codex/README.md to ~/.codex/config.toml. The first time, Codex asks you to approve the new hook. The renderer switches to a plain two-line format in the app automatically.

Antigravity and VS Code

Build and sideload the extension from antigravity/README.md. It adds a status-bar button and a Show Devotional command.

Settings

Optional file at ~/.claude/while-you-wait.json:

{ "mode": "rich", "format": "auto", "sound": false, "width": 64 }

mode is the box style in a terminal (minimal, rich, reverent). format is auto, box or plain; plain is used automatically where no terminal is detected, such as the desktop app.
