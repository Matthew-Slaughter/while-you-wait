while you wait

A verse, a catechism answer, a hymn stanza or a theologian's line, each time you press enter in Claude Code.

“The LORD is my shepherd; I shall not want.”

Psalm 23:1 (ESV)

Spurgeon: 'I shall not want' is the conclusion of a syllogism whose premise is the Shepherd. The Shepherd determines the supply, not your shortage. To want is to forget Whose flock you are in.

An entry from the corpus. 1,682 of them: 499 verses, 289 quotations, 701 creed and catechism answers, 193 hymn stanzas.

Install

One line in a terminal. Then start a new session.

curl -fsSL https://matthew-slaughter.github.io/while-you-wait/install.sh | sh

The script is forty lines. It checks for the claude command and runs the two plugin commands below. It downloads nothing itself.

Without the script:

claude plugin marketplace add Matthew-Slaughter/while-you-wait && claude plugin install while-you-wait@while-you-wait

Or inside a session, in the terminal or in the desktop app's Code tab. They share one configuration.

/plugin marketplace add Matthew-Slaughter/while-you-wait
/plugin install while-you-wait@while-you-wait

New entries arrive when you update the plugin. To have that happen on its own: /plugin, Marketplaces, while-you-wait, Enable auto-update.

What it is

A hook that runs when you submit a prompt. It picks one entry and prints it to your terminal. The entry is not sent to the model and does not change what Claude does. There is no network call and no account.

The text is never written by a model. Scripture is checked against the published translation. Every quotation, creed and hymn is copied from a source you can open, and a script proves the words are there before an entry can ship. The reflection under each entry is one or two sentences, written to be read in the time it takes Claude to answer. How the corpus was built, including the audit that found fabricated quotations in the first version and what was done about it.

Claude Desktop: Chat and Cowork

Those tabs have no hook. There, the devotional is something Claude includes at the start of a conversation: one entry per day, the same all day, printed by a small script. Three steps, once.

  1. Download the skill: while-you-wait-skill.zip. In the desktop app or claude.ai, go to Customize, Skills, Add, and upload it. Code execution must be on, under Settings, Capabilities.
  2. Add one sentence to Settings, Profile, personal preferences, so Claude runs the skill in every conversation:
Begin each new conversation by running the while-you-wait skill and showing its entry, verbatim, before anything else.
  1. For a daily one in Cowork, schedule a recurring task with this prompt. Each run appears in the Scheduled list.
Run the while-you-wait skill and show today's entry verbatim. Then stop.

Claude decides when a skill applies, so a conversation may now and then open without one. Ask for a verse and it will.

Codex

Clone the repository and add the hook from codex/README.md to ~/.codex/config.toml. Codex asks you to approve the new hook once. In the Codex app the entry prints as two plain lines.

Antigravity and VS Code

Build and install the extension from antigravity/README.md. It adds a status bar button and a Show Devotional command.

Settings

Optional, in ~/.claude/while-you-wait.json.

modeBox style in a terminal: minimal, rich or reverent.
formatauto, box or plain. Plain is two lines with no color. Auto uses it where there is no terminal, such as the desktop app.
widthBox width in columns, 40 to 100.
soundtrue plays a quiet chime on macOS.
